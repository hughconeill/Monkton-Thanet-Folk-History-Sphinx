# Sources

Every factual claim on this site should trace back to something
listed here. Organized by record type; add new entries under the
relevant heading as you use new sources. Each heading has an anchor
(shown after the `#` in its section link) so other pages can link
straight to it, e.g. `[Sources](sources.md#parish-registers)`.

```{admonition} Why cite sources so carefully?
:class: note

Village history is often contested or half-remembered. Clear
citations let readers judge the strength of evidence for themselves,
and let future contributors find and re-check the original record.
```

```{admonition} A note on oral history
:class: warning

Oral histories are invaluable but memory can differ from the written
record. Where an oral account and a documentary source disagree, say
so explicitly on the relevant page rather than silently favoring one.
```

## Citation style used on this site

Pages use footnote-style references, e.g.:

```markdown
A claim needing a source.[^my-note]

[^my-note]: Full citation details. See [Sources](sources.md#section).
```

This renders as a numbered footnote at the bottom of the page, with a
link back here for the full record details.
